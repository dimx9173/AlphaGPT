# 36-factor search, 100 iterations: the factor set is exhausted too

Date: 2026-10-03.

## Setup

Fifty real and fifty iid-null walkforward runs, seeds 301-350, 36 features.
Reduced grammar, reward v3, objective v3, train-only selection, 10 generations,
population 16, 5 folds, fixed 12-token genomes, real Binance funding. The two
arms differ only in the data.

Fifty seeds per arm is the first design here with the power to resolve the
effect being chased. At n=8 per cell the fixed-12 arm returned a gap of -1.860
+/- 0.966 and at n=5 the 36-factor arm returned +1.093 +/- 0.635; both were
noise at those sample sizes. This run is what that number actually is.

## Result 1: the gap is not distinguishable from zero

| data | holdout excess Sharpe | beats the hold |
|---|---|---|
| real | -1.559 +/- 0.113 | **0 / 50** |
| null | -1.928 +/- 0.319 | 9 / 50 |

Real minus null: **+0.369 +/- 0.339, t = +1.09**, 95% CI [-0.294, +1.033].

Consistent with zero. The point estimate is positive, and the interval excludes
only effects larger than about -0.3, so a small real advantage is not ruled out.
But nothing here is established, and the 95% CI does not contain an effect big
enough to beat a hold at +1.42.

## Result 2: the null arm beat the hold more often than the real arm

Zero of fifty real runs beat buy-and-hold. Nine of fifty null runs did.

That is the wrong direction, and it is the cleanest statement of the result.
On synthetic data with no edge in it by construction, a randomly-shaped book
beat a constant long nine times in fifty. On the real market it never did.
Whatever the search is doing, it is not finding something that is there.

## Result 3: the search now uses every factor

| arm | distinct factors used | new | old |
|---|---|---|---|
| real | 36 / 36 | 24 / 24 | 12 / 12 |
| null | 36 / 36 | 24 / 24 | 12 / 12 |

At 50 seeds the search touches every factor in the set, in both arms. Most
used on real: WEEKEND (28), ROLL_SPREAD (20), FUND_FLIP_7 (14),
SIGN_ENTROPY_20 (13), VARIANCE_RATIO_8 (12).

This closes the question the expansion was built to answer. The factor set is
not under-used and it is not under-diversified. It is fully available and the
search spends all of it.

## Result 4: the book still leans long

| arm | mean position | at the 0.25 cap | positive coins |
|---|---|---|---|
| real | 0.1225 | 9 / 50 | 19.3 / 28 |
| null | 0.1812 | 23 / 50 | 14.9 / 28 |

One run in five still finishes pinned at the cap. Absolute Sharpe on real data
is +1.115 against a hold of +1.418, so the book is under the hold by 0.30.

## Conclusion

Five variables have now been eliminated by experiment rather than by argument:

| experiment | variable | result |
|---|---|---|
| variable-length A/B | search space | factor subsets reachable went 61.3% -> 99.7%; no edge |
| effort ladder | generations 2/5/10/20 | no dose-response, slope t = -0.43 |
| reward vs gate | v3 vs pure excess | steering worked (position 0.218 -> 0.073, t -3.13); no holdout gain |
| 36f x 10 | factor set | 21 of 24 new factors used; 0 / 5 beat the hold |
| 36f x 100 | factor set, powered | all 36 used; 0 / 50 beat the hold; gap t = +1.09 |

The search is not the constraint and the factor set is not the constraint.
At n = 50 per arm the measured advantage of real data over synthetic data is
+0.37 excess Sharpe with a CI reaching zero, while zero real runs and nine
null runs beat a constant long.

The remaining hypothesis is the one this project has now failed to reject five
times: there is no conditional timing edge in this factor set on this universe
that a genetic search over these formulas can reach. Further widening of the
factor set is the low-value direction, and so is further widening of the
search. What would be worth doing is a question about the DATA (this universe,
this 3-year window, this bar size) rather than about the engine.
