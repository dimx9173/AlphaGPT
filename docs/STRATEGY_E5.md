# STRATEGY E5 — 動態權重與波動擇時 (Dynamic Weights & Timing)

> 任務 E5：鏡像 AC/Z1 引擎，另導出 per-bar net；4 動態方案（各在 Z1 基線上，滾動窗 200/100）與靜態 50/50 對比於 H2/B/C/FULL + 12fold；報告動態權重時序的翻轉率與 turnover 增量；判定 dual-win H2+FULL 且 to_inc<0.015 則採納否則維持靜態。
> 基線：`FORMULA [3,2,7,2,7,11,15,4,4,6,6,10]`，Z1 `ETC 0.88/0.12/cd18/None/ts24 + TRX 0.85/0.12/cd6/0.05/ts24, vt0.012/w12, q0.3, 50/50, aster 2x fund0.0005 fee0.0004`（AC 驗證 Z1 50/50 在 B+C 最優，peak 平坦 ±0.02，rp 與第三腿已 REJECT）。
> 切片：H2[6077:6570] n493 / B[6380:6580] n200 / C[6080:6580] n500 / FULL[0:6580] n6580。12 折 6580//12≈548。
> 引擎：逐片 `build_mats(full[a:b])` + `leg_series(MemeBacktest + quantile_mask_long + cooldown/stops/vol_scale + roll1 + fee/funding/liq)`，動態權重在該片的 per-bar net 上滾動重算（非 FULL 網格切片），turnover 動態 = `w*turn_leg + |dw|*0.5` 的均值。

---

## 方法

### 引擎鏡像與 per-bar net
- 數據：`data/data_15m_3y/{ETC,TRX}.csv` 15m→4h（16 根合成 1），Z1 參數逐腿獨立 `MemeBacktest(aster, lev2, short, lth/sth/cd/sl/ts, vt/vw)`。
- 長門檻為 `quantile_mask_long(q0.3)`（僅限制 `lp`，復現 `run_ac.py` / `run_z1.py` 寫法），隨後 `cooldown → stops → vol_scale → roll1`。
- 逐片（H2/B/C/FULL）分別 `build_mats`，故 `quantile` 的 top-k 閾值逐片重算；靜態對比因此精確復現 AC 的 `H2 5.013 / B 7.042 / C 4.666 / FULL 2.064`。
- 另對 12 折每折 `~548bar` 獨立建腿以得 `fold12` 分布；fold 內動態同樣滾動重算。

### 4 動態方案（定義）
| 代號 | 名稱 | 滾動 | 權重規則 | warmup |
|------|------|------|----------|--------|
| A | sharpe 加權 | 200bar sharpe | `w = clip_sharpe(≥0) / sum(clip_sharpe)`，sharpe=`mean/std*sqrt(2190)` 於 `t-window:t` | t<200 → 50/50 |
| B | 1/vol 加權 | 200bar 擇時、20bar vol | `w = (1/vol_20) / sum(1/vol_20)`，`vol_20 = std(net[t-20:t])` | t<200 → 50/50 |
| C | 擇時雙腿 | 200bar sharpe | 若某腿 trailing sharpe<0 則該腿權置 0（單腿），否則 50/50；雙<0 → 50/50 | t<200 → 50/50 |
| D | 動量偏置 | 100bar cum | 若 `cum_ETC(100) > cum_TRX(100)` 則 `0.6/0.4` 否則 `0.4/0.6` | t<100 → 50/50 |

- 組合：`combo_dyn[t] = wETC[t]*netETC[t] + wTRX[t]*netTRX[t]`。
- turnover：`to_dyn = mean_t( wETC[t]*turnETC[t] + wTRX[t]*turnTRX[t] + |wETC[t]-wETC[t-1]|*0.5 )`，`turn_*` 為腿的 `|dpos|`。增量 `to_inc = to_dyn - to_static`，`to_static = (toETC+toTRX)/2`（即 AC 的 turnover）。
- 權重時序：`wETC_mean/std`、`flip_rate = P(|dw|>0.02)`、`weight_drift = mean|dw|`、每片抽樣 `wETC_sample`。

### 判定
- 若任一動態 **同時** `sharpe_H2 > static_H2` 且 `sharpe_FULL > static_FULL` 且 `to_inc_FULL < 0.015` 則採納，否則 `KEEP_STATIC_50_50`。

## 判定

| 方案 | dual_win (H2 & FULL) | inc_FULL | 採納？ |
|------|----------------------|----------|--------|
| A | False (-0.359, -0.626) | 0.012961 | 否 |
| B | False (-0.043, -0.075) | 0.017465 | 否（且超 turnover 閾） |
| C | False (+0.000, -0.521) | 0.009248 | 否 |
| D | False (-0.294, -0.101) | 0.004084 | 否 |

- **0/4 滿足 `dual_win && inc<0.015`**，故 **`KEEP_STATIC_50_50`**。
- 與 AC 一致：Z1 50/50 的峰值平坦（±0.02）並非可追趨勢；以滾動 sharpe/vol 擇權重僅增加權重噪聲與換手（+0.004–0.017），不增夏普；以 H2 滾動擇時（方案 C）則在 H2 段幾乎不觸發、而在 FULL 早段誤殺導致 FULL 大跌 0.52。
- 建議：維持 AC 結論 `Z1 + 50/50 + 無第三腿 + 無 rp + 無動態`；未來僅在更長樣本或 regime 標籤下重探擇時，或以 OOS 鎖定的 vol_target 再試 `vt` 動態（而非權重動態）。
