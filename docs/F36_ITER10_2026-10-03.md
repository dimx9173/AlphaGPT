# 36-factor search: 10 iterations against the 12-factor baseline

Date: 2026-10-03. Commit after cbd9a27.

## Setup

Five real and five iid-null walkforward runs, seeds 201-205, all at 36 features.
Reduced grammar, reward v3, objective v3, selection keyed on train only, 10
generations, population 16, 5 folds, fixed 12-token genomes, real Binance
funding. Both arms differ only in the data, so the comparison is the
real-null gap computed inside the 36-factor arm.

This is smaller than the recorded pilot (25 generations, 10 folds) and no gate
was applied. It is a diagnostic.

## Result 1: the search uses the new factors, and widely

| | factors used |
|---|---|
| new (indices 12-35) | 21 of 24 |
| old (indices 0-11) | 7 of 12 |
| distinct across 10 runs | 28 |

Most-used: WEEKEND (7), AUTOCORR_20 (5), FUND_X_MOM (5), FUND_LAST (4),
SIGN_ENTROPY_20 (4). The session and funding families, which are the ones the
correlation measurement showed are nearest to orthogonal to everything else,
are also the ones the search reaches for most. The wiring works.

## Result 2: nothing beats buy-and-hold

| data | holdout excess Sharpe | beats the hold |
|---|---|---|
| real | -1.668 +/- 0.444 | 0 / 5 |
| null | -2.761 +/- 0.454 | 0 / 5 |

Buy-and-hold on the real holdout is +1.418 and the best real run reaches +1.721
absolute, which is still 0.30 short of it. Zero of five.

## Result 3: the real-null gap points the right way and is not significant

Real minus null: **+1.093 +/- 0.635, t = +1.72** on 5 seeds per arm.

Direction is right, magnitude is not established. Five seeds per arm cannot
resolve an effect this size; the same n on the fixed-12 arm produced a gap of
-1.860 +/- 0.966, so this is a sign change on a quantity that has moved sign
before at this sample size.

## Reading

The 36-factor set is doing what it was built to do. The search uses it, and
prefers the families that were measured to be orthogonal. That is a real
result and it closes out the item: the factor set is no longer the binding
constraint on the search's behaviour.

It is not an edge. Nothing beat the hold in either arm. The honest summary is
that widening the factor set by 3x changed WHICH factors the search reaches
for and did not change WHAT it achieves.
