# 1h bars with the multi-timeframe block: 100 iterations, and the bar-size question answered

Date: 2026-10-03. 50 real + 50 iid-null walkforward runs, seeds 401-450.

## Setup

1h bars, 41 factors (the 36 plus the 5 measured multi-timeframe survivors), reduced
grammar, reward v3, objective v3, train-only selection, 10 generations, population
16, 5 folds, fixed 12-token genomes, real Binance funding.

`--scale-windows` halves the factor window lengths so their horizons stay at their
30m values. Without it, doubling the bar size doubles every lookback and the run
tests sampling and horizon together, which is not a bar-size question.

The 1h set was backfilled to the same span as the 30m set before this ran: 18026
common bars, 2.06 years, zero off-grid gaps, against the 30m set's 35553 bars over
2.03 years. Both profiles span 2024-09-13 to 2026-10-04 on the 28-coin intersection,
bounded by POL which listed 2024-09-13.

## Result 1: the real-null gap is significantly NEGATIVE

| data | holdout excess Sharpe | beats the hold |
|---|---|---|
| real | -2.611 +/- 0.143 | 1 / 50 |
| null | -1.599 +/- 0.173 | 3 / 50 |

Real minus null: **-1.012 +/- 0.224, t = -4.52**, 95% CI [-1.452, -0.573].

This is the first statistically significant real-null gap in the project, and it
points the wrong way. Real data does significantly WORSE than synthetic data for
this search. The 30m run at the same n returned +0.369 +/- 0.339, indistinguishable
from zero.

## Result 2: excess is not comparable across bar sizes, and the benchmark is why

| | buy-and-hold | strategy absolute Sharpe | shortfall |
|---|---|---|---|
| 30m | +1.418 | +1.115 | 0.302 |
| 1h | **+3.106** | +2.090 | **1.016** |

The 1h window covers 2024-09 onward, which is a strong bull stretch for this
universe, so passive long is worth +3.11 against +1.42 on the longer 30m window.
Reading the 1h excess of -2.611 as "worse than the 30m result" would be wrong on
its own terms: the bar it has to clear is 2.2 times higher. Measured as a shortfall
against the hold, 1h is worse by 3.4x.

## Result 3: the multi-timeframe factors are used, heavily

All 41 factors appear across the 50 real runs, and all 5 MTF factors are used.
Most-used overall is `4h_PARKINSON` at 30 appearances, ahead of every 1h factor.
Then `4h_EFFICIENCY` (12), `4h_SKEW` (9).

The search prefers the coarsest grid's volatility estimate, which is the one with
the least sampling noise per unit of memory. That is the multi-timeframe thesis
working as designed and it is worth knowing. It is not worth much on its own: a
factor the search leans on is a factor the search can overfit.

## Result 4: real data does carry information, it is just not tradable

| arm | mean position | at the 0.25 cap | positive coins |
|---|---|---|---|
| real | 0.0350 | 2 / 50 | **22.4** / 28 |
| null | 0.0619 | 4 / 50 | 13.9 / 28 |

Real data produces 22.4 positive legs against the null's 13.9. Breadth separates
cleanly. Excess does not, and breadth without excess is a book that is long more
often in a rising market, which is drift, not timing.

## What the six experiments now say

| experiment | variable | result |
|---|---|---|
| variable-length A/B | search space | reachable factor subsets 61.3% -> 99.7%; no edge |
| effort ladder | generations 2/5/10/20 | no dose-response; slope t = -0.43 |
| reward vs gate | v3 vs pure excess | steering worked (position 0.218 -> 0.073, t -3.13); no holdout gain |
| 36f x 100 | factor set | 0/50 beat the hold; gap +0.369 +/- 0.339, t = +1.09 |
| 41f MTF x 100 | multi-timeframe | 5/5 MTF factors used; no edge |
| **1h x 100** | **bar size** | **gap -1.012 +/- 0.224, t = -4.52, significantly negative** |

The last row is the informative one and it is not what was expected. A significantly
NEGATIVE real-null gap means real data is systematically worse for this search than
data with no structure in it. That is the signature of selection overfitting rather
than of a missing edge: the train window on real bars contains structure the search
can fit and cannot keep, while on synthetic bars there is less to fit.

## Where that leaves the project

Six variables have been eliminated by experiment rather than by argument. The
remaining hypothesis is one this project has now failed to reject seven times: there
is no conditional timing edge in this factor set, on this universe, at this bar size
or that one, that a genetic search over these formulas can reach.

The one measurement that moves in the right direction is breadth: 22.4 positive
legs on real against 13.9 on null. That is not tradable edge, and reporting it
without the excess number next to it would be reading drift as discovery. But it is
the only thing in six experiments that points anywhere, and it says the real data
does contain structure the search responds to.
